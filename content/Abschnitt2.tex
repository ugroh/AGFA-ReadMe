\subsection{Aufzählungen: Das Paket \texttt{agfa-listen.sty}}\label{subsec:agfa-listen}
%
Mit Hilfe des Paketes \lpkg{enumitem} ist es einfach \emph{Aufzählungen} zu erstellen, die wir in 
%
\begin{tcolorbox}
agfa-listen.sty
\end{tcolorbox}
%
zusammengefasst und erweitert haben.

Alle Listen dieser Vorlage beruhen auf \lpkg{enumitem} (siehe \textcite{enumitem}).
Wer eine Liste anders gestaltet haben oder eine eigene definieren will, findet dort alle Möglichkeiten; die eigenen Definitionen gehören dann in die eigene Definitionsdatei und nicht in \texttt{agfa-listen.sty}.
So ist etwa \texttt{myenumerate} definiert als
%
\begin{tcblisting}{listing only}
\newlist{myenumerate}{enumerate}{2}
\setlist[myenumerate,1]{%
	label=\upshape(\roman*),
	leftmargin=1em,
	itemindent=2em
}
\end{tcblisting}
%
Einzelne Einstellungen lassen sich auch direkt beim Aufruf ändern, etwa \verb|\begin{enumerate}[(i)]| für die Zählung oder \texttt{nosep} für kompakte Abstände.

Dazu einige Beispiele: 
%
\begin{tcblisting}{title= Nummerierte Listen, sidebyside }
\begin{enumerate}[(i)]
\item
Erstes Item
\item
Zweites Item
\item
\ldots
\end{enumerate}
\end{tcblisting}
%
\begin{tcblisting}{title= Äquivalenzen, sidebyside }
\begin{enumerate}[(a)]
\item
Erstes Item
\item
Zweites Item
\item
\ldots
\end{enumerate}
\end{tcblisting}
%
\begin{tcblisting}{title= Inline}
\begin{enumerate*}[(1)]
\item
Dies ist ein Typoblindtext. 

\item
Oder manchmal Sätze, die alle Buchstaben des Alphabets enthalten - man nennt diese Sätze \enquote{Pangrams}. 

\end{enumerate*}
\end{tcblisting}
%

%
\begin{docEnvironment}{myequivalent}{\oarg{options}}
\end{docEnvironment}
%

Diese eignet sich für Aufzählungen, bei denen die einzelnen Items länger sind und über mehrere Zeilen gehen.

Vorab noch eine Anmerkung zur Eingabe eines mathematischen Textes: Auch hierfür gelten einige typographische Regeln, die zu beachten sind.

\minisec{Einfachere Eingabe von Klammern \etc}
Will man etwa Klammern \enquote{ ( \ldots ) } in der Größe an das anpassen, was zwischen ihnen steht, muss man gewöhnlich mit \cs{big\ldots} oder \cs{left}/\cs{right} arbeiten. 
Dies kann man sich ersparen, da ein Makro eingearbeitet ist, das einem diese Arbeit abnimmt: Im Mathemodus sind ( ) und [ ] aktiv und passen sich automatisch an.
Zwei Dinge sind dabei zu beachten:
%
\begin{myitemize}[nosep]
\item
Halboffene Intervalle wie $ \lointerval{a,b} $ nicht direkt als \verb|]a,b]| tippen, sondern \cs{lointerval}, \cs{rointerval} \bzw \cs{ointerval} verwenden.
\item
Eine Klammer nicht über \verb|&| oder \verb|\\| (etwa in \texttt{align}) hinweg öffnen oder schließen; siehe hierzu auch den Hinweis zu mehrzeiligen Klammern im \texttt{README.md}.
\end{myitemize}
%
\begin{dispExample*}{title=Ein Beispiel}
Also 
%
\[
( \frac{1}{1 - \sum_{j=1}^{n}r_{j}} )
\]
%
\bzw
%
\[
\lointerval{ \frac{1}{1 - \sum_{j=1}^{n}r_{j}} } 
\]
%
eingeben; wie es aussieht sieht man unten.
\end{dispExample*}

\minisec{Weitere Tools: }
Der Ausdruck 1/2 in einem Fließtext ist nicht schön, aber \sfrac{1}{2} ist es schon; im Mathemodus leistet dies \cs{mfrac}, also $ \mfrac{E}{F} $ statt $ E/F $.
Will man \cs{sfrac} im Mathemodus nutzen, dann über \verb|\text{\sfrac{E}{F}}|.
Es ist $ \interior{A} $ das Innere einer Menge eines topologischen Raums.
Eine Übersicht ist in der folgenden Tabelle enthalten.
%
\begin{center}
\begin{tabular}{l  l l }
\docAuxCommand{sfrac\brackets{a}\brackets{b}} (Text)	&   &   \sfrac{a}{b}   	\\
\docAuxCommand{mfrac\brackets{E}\brackets{F}} (Mathemodus)	&   &   $ \mfrac{E}{F} $	 \\
\docAuxCommand{interior\brackets{A}}  	&   &   $ \interior{A} $	 \\ 	
\end{tabular}
\end{center}

Und immer daran denken: $ \dfrac{ \pi }{ 2 } $ geht nur so  und nicht so $ \pi/2 $.
